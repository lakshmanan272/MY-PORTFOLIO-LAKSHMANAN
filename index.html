A voice- and text-controlled desktop agent that clicks, types, scrolls, opens apps and manages windows. Speech recognition, wake word and text-to-speech all run offline, intent routing takes about 21 µs, and actions land in under 400 ms from the last syllable.

BookMyEvent — Oversell-Safe Ticket Booking

A full-stack booking app whose booking path cannot oversell under concurrent load: a pessimistic row lock (SELECT … FOR UPDATE) guards every seat, proven by a 30-thread race test. Stateless JWT auth, role-based access, Caffeine caching, Docker, and a k6 load test.

MiniRedis — A Redis Clone in C

Written from scratch with only the C standard library and POSIX: speaks the real Redis RESP protocol, supports TTL expiry with a background sweeper, and provides a SET NX PX distributed lock plus an HTTP gateway that BookMyEvent's booking lock can run on.
